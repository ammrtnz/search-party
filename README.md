# Search Party 🔎

A cozy word-path puzzle, inspired by LinkedIn's Wend. 90 levels.

**How to play:** Four words are hidden in the grid — 3, 4, 5, and 6 letters long.
Trace each word through adjacent tiles (up/down/left/right). Every tile is used
exactly once, and words never share tiles. Drag to trace, or tap tile by tile.
Stuck? The 💡 Hint button reveals the next letter of the shortest unsolved word.

## Development

Plain HTML/CSS/JS — no build step. Serve the folder with any static server:

```sh
npx http-server . -p 8642
```

### Regenerating puzzles

Puzzles live in `puzzles.js`, generated by:

```sh
node tools/generate.mjs 90 7    # count, seed
node tools/verify.mjs           # independent sanity check
```

The generator packs four words as orthogonal self-avoiding paths that exactly
tile an 18-cell grid, then verifies each puzzle has exactly one valid solution.
Word lists are in `tools/words.mjs`.
